# BathyTrace 0.1.0 — 2026-10-29

First BathyTrace release prepared for publication.

- GeoTIFF contour extraction and assisted/manual tracing.
- Conservative gap joining and review of inferred connections.
- Depth sequence previews, individual depth values and editing undo.
- GeoPackage, GeoJSON, 3D Shapefile and 3D DXF export.
- BathyTrace name, requested description and prominent Mohamed Hamouda copyright.

The supplied source previously used the development name Contour Studio and version 1.2.1. BathyTrace public numbering begins at 0.1.0.
